# Guardian and minor consent flow

Students are asked for the minimum profile data: display name, age band, school when relevant, language, and versioned consent. A guardian relationship begins as pending and becomes verified only after an explicit invite/acceptance flow. A guardian cannot read every report merely because they know a student's email.

The local provider includes one verified demo relationship (`demo-guardian` → `demo-student`) for testing dependent checkout. Production policy, retention, age thresholds, and report visibility require Indonesian legal review before activation.
