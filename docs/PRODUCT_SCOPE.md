# Product scope

IAQ V1.0 connects five modules: IAQ Assess, IAQ Compass, IAQ Tracker, IAQ Report, and IAQ School. The product helps a student build a useful direction conversation from cognitive signals, interests, academic evidence, projects, and real exploration.

V1.0 is an experimental educational profile. It does not diagnose, rank, label destiny, or claim an officially normed IQ.

## V1.0 journey

1. Student reviews consent and starts a cognitive baseline.
2. The session records answers, timing, interruptions, and completion state.
3. Server-side scoring produces seven relative domain signals and a provisional composite.
4. Compass combines RIASEC-style interests with academic and activity evidence.
5. Transparent matching shows fit, readiness, feasibility, confidence, reasons, and next evidence.
6. Tracker stores dated profile snapshots and exploration progress.

## Deferred

External authentication, production Postgres repository wiring, psychometric calibration, full item-authoring CRUD, guardian portal, university-source ingestion, and LLM narrative generation are prepared as seams but require the next milestone and real governance.
